# Tasks & Handoffs screenshots

These screenshots show the real plugin running in Paseo's web app, connected to an isolated
Paseo daemon. The daemon has a made-up home folder, and a stand-in for `claude-tools` that
returns only fictional tasks, people and paths. No real task database, history or user data
is involved. The phone-sized images come from the web app at a phone's screen size, not from a
native phone app.

- `tasks-list-desktop.png`: the task list with in-progress, open and blocked tasks.
- `tasks-list-mobile.png`: the same list on a phone-sized screen.
- `tasks-detail-desktop.png`: one task's details: record source, description, notes and acceptance criteria.
