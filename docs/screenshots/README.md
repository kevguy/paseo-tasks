# Synthetic Tasks & Handoffs screenshots

These screenshots render the real `TasksScreen` component in a browser with a local mock RPC that returns only fictional example records. No host Beads database, task history, workspace path or user data is connected. The narrow image is a mobile-sized web layout preview, not a native-phone capture.

- `tasks-list-desktop.png`: task list with active, blocked and open sample records.
- `tasks-list-mobile.png`: the same list at a narrow viewport.
- `tasks-detail-desktop.png`: task details with synthetic description, acceptance criteria, dependency, handoff and continuation text.
